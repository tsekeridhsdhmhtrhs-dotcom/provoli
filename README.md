# Προβολή Κουτιού

Η σελίδα που ανοίγει από το QR της ετικέτας του 3D Studio Pro: μόνο το 3D ενός Κουτιού, με το κομμάτι της
ετικέτας φωτισμένο. Το σχέδιο είναι μέσα στον σύνδεσμο (μετά το `#`), συμπιεσμένο· η σελίδα δεν διαβάζει και δεν
γράφει τίποτα πουθενά. Κάθε Κουτί έχει το δικό του QR.

Τα αρχεία στο `src/` είναι αντίγραφα από το 3D Studio Pro (εκεί: `tools/provoli-sync.sh`), χωρίς Δουλειές, τιμές ή Παρτίδες.
